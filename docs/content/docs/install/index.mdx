title: 安装方式
description: 五种安装方式的对比：一行脚本、Docker 镜像、Docker Compose、发布包与源码构建。

ImgYoung 是一个纯 Go 编写的单个二进制文件，管理后台的前端已经编译在里面。运行时不需要数据库服务、缓存或其他进程。

五种安装方式装出来的是同一个程序，区别只在于怎么拿到它、由什么来托管它。

## 对比

| 方式 | 适合 | 需要 root | 升级 | 数据目录 |
|---|---|---|---|---|
| [一行安装脚本](./script.mdx) | 在 Linux 或 macOS 主机上直接运行；Linux 上可交给 systemd 托管 | 装到 `/usr/local/bin` 或加 `--service` 时需要，装到 `~/.local/bin` 不需要 | 重新执行同一条命令 | 加 `--service` 时为 `/var/lib/imgyoung`，否则为启动时当前目录下的 `data/` |
| [Docker 镜像](./docker.mdx) | 已经在用 Docker 的主机 | 取决于主机上 Docker 的权限设置 | 拉取新镜像，重建容器 | 挂到容器 `/data` 的卷 |
| [Docker Compose](./compose.mdx) | 想把部署写成文件，或与反向代理一起编排 | 同上 | `docker compose pull`，再 `docker compose up -d` | 卷 `imgyoung-data`，实际名称带 Compose 项目名前缀 |
| [发布包](./binary.mdx) | Windows；不便执行安装脚本；想手动控制每一步 | 不需要 | 下载新包，替换二进制后重启 | 启动时当前目录下的 `data/`，可用 `IMGYOUNG_DATA_DIR` 指定 |
| [源码构建](./source.mdx) | 要改代码或自己构建的开发者 | 不需要 | 拉取新代码，重新构建 | 同发布包 |

不确定选哪个：有 Docker 就用 [Docker Compose](./compose.mdx)；没有 Docker 的 Linux 主机用[一行安装脚本](./script.mdx)加 `--service`。在群晖、1Panel、宝塔、CasaOS、Unraid 这类带图形界面的系统上部署，见 [NAS 与服务器面板](./nas-panel.mdx)。

## 不适合的环境

ImgYoung 是常驻进程，要把数据写在本地磁盘上，下面两类环境跑不了或不适合：

- **只能托管静态页面或按请求运行函数的平台**，如 Cloudflare Workers 与 Pages：无法运行这个 Go 二进制。
- **没有持久磁盘，或空闲时会休眠的平台**，不少托管平台的免费档就是这样：重启后数据丢失；休眠后的第一个请求要等冷启动，图片链接容易超时。


## 各方式共同的部分

- **监听地址**：默认 `:8721`，即所有网卡的 8721 端口，可用环境变量 `IMGYOUNG_LISTEN` 修改。
- **首次登录**：浏览器打开 `http://<主机>:8721/`，用 `admin` 和首次启动日志里打印的初始密码登录，后台会要求立即修改密码。初始密码也可以用环境变量 `IMGYOUNG_ADMIN_PASSWORD` 指定。
- **数据目录**：存放元数据库 `imgyoung.db`、主密钥 `master.key`、内置 local 渠道的 `blobs/` 与衍生图缓存 `variants/`。要备份整个目录，并单独备份一份 `master.key`。
- **配置**：启动所需的少量引导配置用 `IMGYOUNG_*` 环境变量设置，其余运营配置都在后台修改，保存即生效。没有配置文件。见[配置](../configuration.mdx)。
- **进程管理器**：长期运行时，要交给会在进程退出后自动重启它的托管方式，如 systemd（`Restart=always`）或 Docker（`--restart unless-stopped`）。后台「设置 → 备份与导出」里的「恢复」会让服务正常退出，由进程管理器重新启动时才换入快照。仓库 `deploy/` 下的示例都已这样配置。

<Callout type="info" title="为什么没有 go install">
  `go install` 只拿仓库源码现场编译。管理后台的前端是构建产物，不在仓库里，这样装出来的二进制只有接口、没有后台页面。在本机安装请用一行脚本或发布包，不需要 Go 工具链。

  Go 开发者要复用的通常是存储引擎，它是可以 `go get` 的公开包，见 [Go 库](../library/index.mdx)。
</Callout>
