## 选择发布包

到[发布页](https://github.com/x-haose/imgyoung/releases)下载对应平台的压缩包：

| 系统 | amd64 | arm64 |
|---|---|---|
| Linux | `imgyoung_<版本号>_linux_amd64.tar.gz` | `imgyoung_<版本号>_linux_arm64.tar.gz` |
| macOS | `imgyoung_<版本号>_darwin_amd64.tar.gz`（Intel）| `imgyoung_<版本号>_darwin_arm64.tar.gz`（Apple 芯片）|
| Windows | `imgyoung_<版本号>_windows_amd64.zip` | `imgyoung_<版本号>_windows_arm64.zip` |

文件名里的版本号不带 `v`（如 `1.0.0`），下载地址里的标签带 `v`（如 `v1.0.0`）。同一目录下的 `checksums.txt` 列出每个包的 sha256。

包里的内容：

<Files>
  <File name="imgyoung（Windows 为 imgyoung.exe）" />
  <File name="LICENSE" />
  <File name="README.md、README.en.md" />
  <Folder name="deploy" defaultOpen>
    <File name="compose.yaml" />
    <File name="Caddyfile" />
    <File name="nginx.conf" />
    <File name="imgyoung.service" />
  </Folder>
  <Folder name="web">
    <Folder name="licenses" />
  </Folder>
</Files>

二进制不依赖包里的其他文件，可以单独拷走。`deploy/` 是 Docker Compose、反向代理与 systemd 的示例配置，`web/licenses/` 是管理后台所用第三方代码的许可证。

## 下载与校验

以 1.0.0 为例，换成你要装的版本与架构：

<Tabs items={['Linux', 'macOS', 'Windows']}>
<Tab value="Linux">

```bash title="终端"
VERSION=1.0.0
FILE=imgyoung_${VERSION}_linux_amd64.tar.gz
BASE=https://github.com/x-haose/imgyoung/releases/download/v${VERSION}
curl -fLO "$BASE/$FILE"
curl -fLO "$BASE/checksums.txt"
grep " $FILE\$" checksums.txt | sha256sum -c -
tar -xzf "$FILE"
```

</Tab>
<Tab value="macOS">

```bash title="终端"
VERSION=1.0.0
FILE=imgyoung_${VERSION}_darwin_arm64.tar.gz
BASE=https://github.com/x-haose/imgyoung/releases/download/v${VERSION}
curl -fLO "$BASE/$FILE"
curl -fLO "$BASE/checksums.txt"
grep " $FILE\$" checksums.txt | shasum -a 256 -c -
tar -xzf "$FILE"
```

二进制没有开发者签名，也没有经过 Apple 公证。用 `curl` 下载的文件可以直接运行。用浏览器下载的包，解压后要先去掉隔离属性，否则系统会阻止它运行：

```bash title="终端"
xattr -d com.apple.quarantine imgyoung
```

</Tab>
<Tab value="Windows">

```powershell title="PowerShell"
$Version = "1.0.0"
$File = "imgyoung_${Version}_windows_amd64.zip"
$Base = "https://github.com/x-haose/imgyoung/releases/download/v$Version"
Invoke-WebRequest "$Base/$File" -OutFile $File -UseBasicParsing
Invoke-WebRequest "$Base/checksums.txt" -OutFile checksums.txt -UseBasicParsing
$Expected = foreach ($Line in Get-Content checksums.txt) {
  $Hash, $Name = $Line -split '\s+'
  if ($Name -eq $File) { $Hash }
}
$Actual = (Get-FileHash $File -Algorithm SHA256).Hash
if (-not $Expected -or $Actual -ne $Expected) { throw "sha256 不符:期望 $Expected,实际 $Actual" }
Expand-Archive $File -DestinationPath imgyoung
```

</Tab>
</Tabs>

校验通过时，Linux 与 macOS 输出 `<文件名>: OK`，PowerShell 不报错。校验不通过就不要使用这个包，重新下载。

## 运行

<Tabs items={['Linux / macOS', 'Windows']}>
<Tab value="Linux / macOS">

```bash title="终端"
./imgyoung
```

</Tab>
<Tab value="Windows">

```powershell title="PowerShell"
cd imgyoung
.\imgyoung.exe
```

</Tab>
</Tabs>

浏览器打开 `http://<主机>:8721/`，用 `admin` / `imgyoung123` 登录，首次登录会要求立即修改密码。按 `Ctrl+C` 正常停止服务。

Windows 上首次运行时，防火墙可能询问是否允许 `imgyoung.exe` 访问网络。只在本机使用可以不允许。

### 数据目录

数据目录默认是**启动时当前目录**下的 `data/`，而不是二进制所在的目录。换一个目录启动，就会得到一个全新的空实例。

用 `IMGYOUNG_DATA_DIR` 固定数据目录的位置：

```bash
IMGYOUNG_DATA_DIR=/srv/imgyoung ./imgyoung
```

```powershell
$env:IMGYOUNG_DATA_DIR = "D:\imgyoung-data"; .\imgyoung.exe
```

相对路径在启动时按当时的工作目录解析成绝对路径。实际使用的目录显示在后台「设置 → 运行配置」底部的「引导配置」卡片里。

### 监听地址与命令行参数

- 默认监听 `:8721`，即所有网卡。只给本机的反向代理使用时，设 `IMGYOUNG_LISTEN=127.0.0.1:8721`。其他环境变量见[配置](../configuration.mdx)。
- `./imgyoung -version` 打印版本信息后退出。这是唯一的命令行参数，其余配置都通过环境变量与后台设置。`-h` 只打印用法；带上其他参数时，程序报错退出（退出码 2），不会启动服务。

## 交给进程管理器托管

长期运行时，不要只在终端里开着它。进程管理器负责开机启动，并在进程崩溃后重新启动它。

后台「设置 → 备份与导出」里的「恢复」也依赖进程管理器：恢复时服务会正常退出，重新启动时才换入快照。没有进程管理器，就要手动启动一次才能完成恢复。所以进程管理器要配置成**进程退出后总是重启**，包括正常退出。

- **Linux**：用包里的 systemd 示例。效果与[一行安装脚本](./script.mdx)的 `--service` 相同，数据在 `/var/lib/imgyoung`，各项设置的说明见那一页。

  ```bash title="终端"
  sudo install -m 0755 imgyoung /usr/local/bin/imgyoung
  sudo install -m 0644 deploy/imgyoung.service /etc/systemd/system/imgyoung.service
  sudo systemctl daemon-reload
  sudo systemctl enable --now imgyoung
  ```

- **macOS**：写一个 launchd 服务，或者改用 [Docker](./docker.mdx)。
- **Windows**：用 WinSW、NSSM 等工具把 `imgyoung.exe` 注册为 Windows 服务。设置好工作目录或 `IMGYOUNG_DATA_DIR`，并设置为退出后重启。

## 升级

<Steps>
<Step>

**备份**：建议先在后台「设置 → 备份与导出」点「立即备份」。

</Step>
<Step>

**下载并校验**新版本的包，步骤同上文。

</Step>
<Step>

**替换并启动**：停止服务，用新的二进制替换旧的，再启动。数据目录不用动，数据库结构在新版本启动时自动迁移。

</Step>
</Steps>

换回旧的二进制不能降级：旧版本会拒绝启动被新版本迁移过的数据库。回滚要用旧版本加上升级前的快照，步骤与更多注意事项见[升级](../operations/upgrade.mdx)。
